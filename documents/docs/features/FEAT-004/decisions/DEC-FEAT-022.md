# DEC-FEAT-022: 訂正Evidenceの引用旧命題を検索列へ含める

> **状態:** `decided`  
> **Decision Level:** L3 — Codex workflowの検索・更新契約  
> **対象Feature:** FEAT-004

## 判断

訂正Evidenceの原文に日本語または対応する引用符で囲まれた旧命題が明示される場合、その**完全な引用文**を`search_queries`の二番目の要素として一回だけ追加できる。先頭は常に`proposed_assertion`とする。

## 根拠

訂正Candidateでは新しい命題による検索が空でも、原文に明示された旧命題から既存Assertionを発見し、検索結果に含まれるIDだけを`get`・`get-evidence`・更新の候補にできる。これはID推測や同義語の生成を許可しない。

## 制約

- 引用符で囲まれた完全な旧命題がない訂正には追加しない。
- 引用文の要約・正規化・翻訳・同義語・Scope由来語を生成しない。
- 同じ文字列は一度だけにする。
- `search-text`の空結果は正常であり、次の許可済みqueryへ進む。取得・更新に使うIDは全queryの結果集合だけに限定する。

## 承認

2026-08-16、人間が上記の限定的な検索列拡張を承認した。
